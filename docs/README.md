# Документация Pegas

CLI-утилита на TypeScript для управления обратным прокси-сервером Caddy 2 в связке с Docker на VPS.

* **Рантайм-зависимости:** 0 (ноль сторонних npm-пакетов, только стандартные модули Node 24+: `node:util`, `node:fs`, `node:path`, `node:child_process`).
* **Размер бандла:** ~30 КБ (`dist/index.js`).
* **Инструменты разработки:** Bun 1.4+ (`bun build`, `bun test`, `tsc`).
* **Выходной формат:** исполняемый файл Node.js (`bin/pegas.js`).

## Общие флаги
* `--json` — выводит структурированный JSON вместо форматированного текста (поддерживается всеми командами).
* `--gateway-dir <путь>` — явно указывает каталог шлюза (по умолчанию ищет в текущей папке, `~/gateway` или `~/pegas-server`).
* `-h, --help` — справка по командам.
* `-v, --version` — версия утилиты.

## Тестирование и верификация

1. **Unit-тесты (`bun test`)**:
   - 64 теста в 9 файлах рядом с кодом (`src/**/*.test.ts`): парсинг CLI, генератор Caddyfile, хирургия портов compose, DNS-проверки, анти-хайджекинг, локальный dev, кэш Caddy и табличный вывод.
2. **Unified E2E (`bun run test:e2e`)**:
   - Сквозной 11-фазный рантайм-тест в герметичной песочнице с реальным Caddy, мульти-тенант деплоем, доставкой физического HTTP-трафика (`curl`), защитой от сбоев и оффлайн-кэшем образов в `.cache/images/`.
3. **Локальный Dev E2E (`bun run test:e2e:dev`)**:
   - 5-фазный тест HTTPS-проксирования локального сервера разработки, разрешения конфликтов портов (8443+), изоляции процессов и смарт-поднятия баз данных (`--infra`).
4. **Совместимость с реальными репозиториями (`bun run test:e2e:init <path-or-url>`)**:
   - Автоматическая изолированная проверка выполнения `init` на реальных проектах (подробнее в [документации init](./init.md#3-тестирование-совместимости-на-реальных-репозиториях-e2einit)).
