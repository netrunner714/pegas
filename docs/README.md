# Документация Pegas

CLI-утилита на TypeScript для управления обратным прокси-сервером Caddy 2 в связке с Docker на VPS.

* **Рантайм-зависимости:** 0 (ноль сторонних npm-пакетов, только стандартные модули Node 24+: `node:util`, `node:fs`, `node:path`, `node:child_process`).
* **Размер бандла:** ~30 КБ (`dist/index.js`).
* **Инструменты разработки:** Bun 1.4+ (`bun build`, `bun test`, `tsc`).
* **Выходной формат:** исполняемый файл Node.js (`bin/pegas.js`).

## Сценарии и команды

0. [**ЦА и УТП продукта**](./target-audience.md) — Для кого продукт и его главная ценность.

---

## Общие флаги
* `--json` — выводит структурированный JSON вместо форматированного текста (поддерживается всеми командами).
* `--gateway-dir <путь>` — явно указывает каталог шлюза (по умолчанию ищет в текущей папке, `~/gateway` или `~/pegas-server`).
* `-h, --help` — справка по командам.
* `-v, --version` — версия утилиты.

## Тесты
В папке `tests/` реализованы 4 юнит-теста на `bun:test` ([tests/generator.test.ts](../tests/generator.test.ts)):
* Генерация стандартного прокси с www-редиректом и заголовками безопасности (HSTS, nosniff, Referrer-Policy).
* Пропуск www-редиректа для поддоменов и IP-адресов.
* Генерация SPA + API конфигурации.
* Учёт флага `--no-www`.
