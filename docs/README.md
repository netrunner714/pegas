## Соглашения

1. **Один факт — одно место.** Список команд и флагов живёт в `src/help.ts`
   и генерируется в `docs/reference/cli.md` и `llms.txt`; вручную их не
   редактируют. Поля контракта описаны один раз — в
   `docs/reference/contract.md`.
2. **Язык.** Публичная документация — русская; `llms.txt` — английский
   (адресат — LLM-агенты, им английский понятнее).
3. **Слои.** Публичная документация — тон нейтральный, от третьего лица.
   Внутренние материалы мейнтейнеров — в `docs/internal/`, в агентский
   контекст и публичные файлы не попадают.
4. **Проверка.** `bun run docs:check` (в CI) ловит устаревший
   сгенерированный справочник и битые ссылки.
