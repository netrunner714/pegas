## Правило раздела

1. **Тон.** Внутренние документы могут сохранять личные формулировки владельца
   и черновой стиль — это рабочие материалы. Публичная документация
   (`README.md`, `llms.txt`, `docs/*.md` верхнего уровня) пишется нейтральным
   тоном от третьего лица: только факты о поведении инструмента.
2. **Не копировать дословно.** Формулировки из этого раздела не попадают в
   публичные файлы без переработки в нейтральный тон.
3. **Не попадать в агентский контекст.** `llms.txt` / `llms-full.txt` и вывод
   `pegas llms` генерируются из кода и публичных источников; этот раздел в них
   не включается.
