# Команды управления шлюзом

Набор команд для мониторинга, инспекции и обслуживания маршрутов на сервере.

---

## `pegas list` (алиас: `ls`)
Сканирует каталог `conf.d/*.caddy`.

* Выводит список всех активных доменов.
* Показывает целевой апстрим (`reverse_proxy`), режим работы (Standard / SPA) и наличие www-редиректа.

```bash
pegas list
pegas list --json   # машиночитаемый вывод
```

---

## `pegas remove <домен>` (алиас: `rm`)
Удаляет привязку домена.

1. Удаляет файл `conf.d/<домен>.caddy`.
2. Выполняет `caddy reload --config /etc/caddy/Caddyfile`.

```bash
pegas remove mydomain.ru
```

---

## `pegas reload`
Принудительно валидирует текущую конфигурацию через `caddy validate` и перезагружает Caddy без даунтайма.

```bash
pegas reload
```

---

## `pegas status`
Диагностирует состояние сервера:
* Доступность Docker демона.
* Доступность Docker Compose.
* Наличие Docker-сети `pegasas-network`.
* Статус контейнера `gateway-caddy`.
* Количество зарегистрированных маршрутов в `conf.d/`.

```bash
pegas status
```

---

## `pegas llms`
Выводит в консоль компактный машиночитаемый текст с описанием правил и команд для контекстных окон нейросетей.
