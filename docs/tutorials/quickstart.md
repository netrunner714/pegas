# Быстрый старт

> Цель руководства: за несколько минут получить проект с локальным HTTPS
> в деве и задеплоенный на VPS сайт. Копируйте команды как есть.

## Что понадобится

- Node.js 24+ и Docker на машине разработки;
- VPS с установленным Docker и правами на порты 80/443;
- домен (для прода) с A-записью на IP вашего VPS.

## Шаг 1. Инициализация в проекте

Выполните в корне проекта с `package.json` или `docker-compose.yml`:

```bash
npx @netrunner714/pegas init
```

Команда создаст контракт `pegas.json`, обвяжет скрипты в `package.json`
(`dev`, `deploy`), добавит пакет в devDependencies и сгенерирует
`docs/pegas.md` для ИИ-агентов. Посмотрите результат без записи на диск:

```bash
npx @netrunner714/pegas init --dry-run
```

## Шаг 2. Локальная разработка с HTTPS

```bash
npm run dev
```

Pegas поднимет локальный Caddy-прокси: приложение доступно по адресу
`https://<проект>.localhost`. Для доверенного сертификата (зелёный замок)
один раз установите локальный CA:

```bash
npx pegas ca install
```

Подробнее о HTTPS, портах и авто-подъёме баз данных — в
[руководстве по локальной разработке](../how-to/local-https.md).

## Шаг 3. Деплой на VPS

Скоммитьте изменения, на сервере выполните:

```bash
npm run deploy
# или: npx pegas deploy production
```

Pegas поднимет контейнеры, дождётся их готовности (readiness), настроит
маршруты Caddy и перезагрузит шлюз без даунтайма. SSL-сертификаты Let's
Encrypt выпускаются автоматически при первом обращении к домену.

Проверьте состояние проекта:

```bash
npx pegas status
```
